# Pace Shuttles V2 — Commercial & Communications Large Tranche

This tranche adds:
- Operator route-offer commercial editing (min/max seats, min revenue, threshold, preferred route, post-minimum discount)
- Operator vehicle unavailability using proper date/time modal controls
- Captain passenger operational messaging, including late-running / pickup / weather / operational updates
- Customer support conversations linked to bookings
- Customer post-journey NPS and operator rating feedback
- Customer feedback history
- Protected Supabase views/RPCs and access checks for each role

The production Supabase migration was applied before packaging.

Upload the contents of this package over the GitHub repository root and commit to main. Vercel is the authoritative build validation.
