# Pace Shuttles V2 — T-24 Revenue Rescue

Adds a controlled revenue-gap rescue workflow around the existing V2 rescue tables.

- Site Admin can open/cancel a rescue campaign for an under-threshold vehicle consideration.
- Customer workspace shows eligible rescue offers and supports an optional contribution amount.
- The UI shows an equal-share suggestion while still allowing one party to cover the full remaining gap.
- Contributions start as pending payment transactions; Site Admin can record provider-confirmed payment.
- Campaign completes only when paid contributions bridge the full original gap.
- Journey Detail shows campaign status, remaining gap, close time and customer contributions.

The production Supabase migration was applied before this package was created.
